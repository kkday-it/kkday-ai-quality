# app/api — FastAPI gateway

HTTP 邊界層：路由 → 委派 `app/core/db` + `app/judge`。薄層（業務邏輯下沉 core/judge），
啟動時只做 `db.seed_rules_from_files()`（規則播種，冪等）。

⚠️ **app 啟動刻意不建表**：schema 由 `docker-entrypoint.sh` → `core/db/schema_bootstrap.py` 單一路徑
（`alembic upgrade head`）負責。app 端再跑一次 `metadata.create_all()` 會讓「app 認為的 schema」繞過
migration 直接落地——2026-08-04 實測會讓改名 migration 撞 `DuplicateTable`。

| 項目 | 內容 |
|---|---|
| `main.py` | 僅 app 組裝：`RequestContextMiddleware` + CORS + `seed_rules_from_files()` + `NoActiveReleaseError` → 404 handler + 掛載全部 router（端點實作分散於 `routers/`，各自帶完整 /api 路徑）。`docs_kwargs()` 環境閘：production 關閉 /docs /redoc /openapi.json（schema 面不對未認證流量公開），dev/SIT 保留。`lifespan` 只做 graceful shutdown（收尾進行中 job）。 |
| `routers/auth.py` | 當前身分＋權限清單唯讀端點（/api/auth：**me** / **permissions**）。去帳戶系統（2026-07-22）後本地模式無 register/login/登出/切換帳號，`auth.get_current_user` 回固定身分。GET `/api/auth/permissions` 回當前 user 的 business-key 權限清單（be2 `auth.business-list` **wire 契約 `{value, ttl}`**；前端快取層自記 `startTime` 成 be2 Cache wrapper 形狀，見 `permission.api.ts`），供前端 usePermission() / 選單過濾。 |
| `routers/inbound.py` | 資料錄入（/api/inbound：validate / upload / upload/stream SSE）+ 批次清單（/api/batches）。 |
| `routers/settings.py` | 設定（/api/settings：get/update/raw/test-llm）+ QC DB 連線測試（/api/datasource/qc-db/test）；含 `load_user_context` 守衛 + `_activate_settings`（contextvar 注入 judge 路徑）。 |
| `routers/findings.py` | 級聯樹 GET /api/findings/taxonomy-cascade〔L1→L2 巢狀，供歸因列表篩選 cascader〕+ 評論級歸因歷史（GET /api/attribution-history 時間軸〔prejudge 初判快照／note 備註／failure 初判失敗三類；內部遙測事件由 `_USER_VISIBLE_KINDS` 白名單擋在外〕、POST /api/attribution-history/notes 評論級備註、GET /api/attribution-history/models 歷來初判過的模型清單〔篩選/導出下拉〕），**需登入**。 |
| `routers/evidence.py` | 訂單佐證唯讀查詢（GET /api/evidence/{order_oid}）：與初判管線共用 `db/qc_evidence.get_evidence()`（快取/熔斷/PII 防線同一套），憑證走當前登入 user 的解析；非成功回 status 降級不走 5xx。 |
| `routers/problems.py` | 統一問題列表 / 縱覽聚合（/api/problems*，皆支援 model CSV 多選＝初判模型篩選·當前初判維度）+ 列表導出（POST /api/problems/export → 背景 job；欄尾附 C-1~C-6 六域命中欄〔符合/不符合·未初判留空〕＋「分類統計」「Prompts」工作表；`snapshot_model`＝輸出結果版本〔內容替換為該模型 `attribution_event_lst` 最新快照〕；`compare_models`＝並排對比模型多選〔基準右側每模型附一組情緒/L1/L2 欄，值取該模型最新快照〕——兩者語義獨立可並用）。 |
| `routers/v1/` | 兩 router 皆掛 `prefix="/prejudge"`、`__init__` 聚合於 `/api/v1`（一 router 一領域）：`prejudge.py`（正式批量初判：啟動/筆數預覽 POST `/count`（與啟動同一套標的解析 `_resolve_target_ids`，可 `within_ids` 交集勾選範圍）/SSE `/stream`/暫停 `/pause`/恢復 `/resume`/停止 `/cancel` + 歸因歷史 GET `/runs`·`/runs/{job_id}`——run 級 LLM 使用紀錄，執行中列 overlay in-mem 即時進度；`LlmOverridesIn`/`PrejudgeIn`/`_resolve_target_ids` 為三領域共用契約，由另外兩檔直接 import 重用）｜`prompt_debug.py`（售後根因 ad-hoc 調試：GET `/prompt-debug/defaults` 回**最新草稿**全文（調試台＝草稿工作台）＋ `release_prompt`/`active_release`（軌別切換用，正式版全空時留白）＋單一契約的 schema/欄位卡與兩軌清單、POST `/prompt-debug/drafts` 存為新草稿（`prejudge.run`，**不改線上口徑**；與最新草稿逐字相同則不建檔）、POST `/prompt-debug/releases` 升版·POST `/prompt-debug/releases/{name}/activate` 回退（皆需 `judge-rule.version.manage`）、POST `/prompt-debug/stream` SSE 結構化裁決（`system_prompt` 留空＝用當前正式版），不落 `attribution_tbl`；GET `/prompt-debug/source-item`（`source`+`item_id` → 該筆 canonical 對話原文，供調試文本框一鍵填入；跑批 DB 取數的單筆版，單筆即時不落快照，查無/內容為空 404）；批量跑批 `/prompt-debug/batch/*`——multipart POST `start`（單一配置，另收選填 `config_name` 寫進 manifest 供追溯）·`start-multi`（多**配置**並行，各筆獨立 run；`configs` 為物件陣列、每筆自帶 provider+旋鈕，故同一 model 的不同 effort 可並排比較——舊契約以 model 為 key 會撞碼；配置名重複或供應商未登記整批 400）、GET `groups/{group_id}`（群組進度）·`runs`（列表）·`runs/{run_id}`（進度輪詢）、POST `runs/{run_id}/cancel`·`/resume`（斷點續跑只補未成功筆／`rerun` 全部重打）、GET `runs/{run_id}/files/{kind}`（下載 csv/jsonl/preds/input）；**輸入二選一**——`file` 上傳，或改送 `source`+`item_ids`（貼一串該來源自然鍵，如 session_oid）從來源表撈對話，撈完落成 CSV 快照後路徑與上傳同構，回傳多帶 `db_stats`（要求/撈到/查無/內容為空）；`workers` 為選填覆寫（0＝自動，前端已不送），併發 ceiling 依 model 查表、執行期走 AIMD 自適應；run 摘要多回 `elapsed_sec`/`elapsed_total_sec`/`session_count`；`system_prompt` 留空＝當前正式版，**草稿亦可跑**（manifest `prompt_kind` 標明軌別），本體在 `judge/prompt_debug_batch.py`；**人工評判案例已無 CRUD 端點**——2026-08-04 起案例存於前端本地（Pinia + localStorage），改寫 `/prompt-debug/revise` 與回歸 `/prompt-debug/regression` 由請求整包帶上 `cases[]`，後端純運算不持久化；原掛在 POST `/reviews` 上的兩條契約驗證（欄名須屬 `prompt_debug.OUTPUT_FIELDS`、同欄不得既標對又標錯）已搬進 `PromptDebugCaseIn` 的 validator——那是案例進入後端的唯一入口）。 |
| `routers/rules.py` | 初判規則版本化 CRUD（/api/judge-rules：list/active/history/save/restore/reset + jsonschema 驗證）；POST `/export` 啟動初判 Prompt 包 zip 導出背景 job；POST `/{code}/validate` dry-run 驗證 prompt md（不落庫，內容不合法回 200 `{valid:false,error}`）。**寫入端點（save/restore/reset×2）掛 `require_permission(judge-rule.version.manage)`（admin 級·403）**。 |
| `routers/exports.py` | 通用導出 job 端點（/api/exports：SSE `stream` 進度 / `download` 取檔 / `cancel` 停止），搭 `app/core/export_jobs` 全域 registry，問題列表 / Prompt 包 / 資料包導出共用。 |
| `routers/overview.py` | 質檢概覽真實指標（GET /api/overview/ai-judge：`attribution_tbl` 內容類占比月趨勢 + 總量；「縮窄真接」——外部系統指標不在此，前端維持示意）。 |
| `routers/llm_usage.py` | AI 使用紀錄唯讀聚合（GET /api/llm-usage/overview：KPI〔總成本/總 token/總呼叫/快取〕+ 趨勢〔`granularity` year\|month\|day〕+ 各模型/階段/來源分布；可選 `date_from`/`date_to`）。**只讀不寫**——用量寫入在初判管線內部（`judge/llm/client.py` 的 usage recorder → `llm_usage_lst`）。需登入。 |
| `routers/admin_import.py` | 全庫資料包導出/匯入（/api/admin：POST `/export/start` 啟動導出背景 job〔逐表進度，復用通用 export_jobs，下載走 /api/exports/download〕；POST `/import/validate` 乾跑校驗、POST `/import` 確認匯入背景 job、GET `/import/stream` SSE），委派 `app/core/db/datapack` + `app/core/import_jobs` + `app/core/export_jobs`。匯入只灌白名單表·不執行 SQL；環境閘 `AIQ_ALLOW_DATA_IMPORT`（dev 開）。授權：匯入 `data.datapack.import`、導出 `data.datapack.export`——兩者現在 `default`（人人可用），經可替換權限框架（`app/core/permissions`）判定，日後要收緊只改 `config/global/permissions.json` 的 `default`。 |

> 認證：本地模式無 token（`get_current_user` 回固定身分）；be2 模式 Bearer header 驗簽（見 `core/auth_verifiers.py`）。capability-token 端點（prejudge / 導出 SSE `stream` / import `stream`）以 job_id 免 header，其餘（cancel / download / export / import）仍需認證。
> 授權：破壞性端點掛 `require_permission(key)`（`app/core/permissions`）——無角色，直接授予：rules write＝僅 `grants[email]`（`judge-rule.version.manage`）；inbound 上傳、problems 導出、datapack 導出/匯入、批量初判啟停（`prejudge.run`，消耗 LLM 額度）現行皆在 `default`（登入即可用）；problems / overview 讀端點掛登入最低門檻（`get_current_user`）。`default ∪ grants[email]` 映射見 `config/global/permissions.json`；provider 切換見 `auth.config.json`。
