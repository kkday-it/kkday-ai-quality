■ C-6-2 價值感落差
判定範圍：行程／商品依約正常完成、費用與內容都已寫清楚，旅客只是主觀覺得整體「不值這個價」——嫌貴、CP 值低、價值與價格不相稱，或兌到手的票券／贈品換算下來不如預期划算；核心是「拿價格對比價值的主觀評價」（反饋明確提到價格／票價／費用／划算與否）。與價格無關、純內容不如想像 → 歸 C-6-3；若其實是費用沒寫清、現場臨時加收、被施壓消費，**或不滿實際指向退款／改期／價差退還的規則與結果（買貴了不給退、降價不補差額、申請退款被拒）**等客觀問題，則非本項——本項僅收原文**未提出任何退／改／補差額訴求**、純粹拿價格對比價值的評價。
　✅「行程是順利完成啦，但這個價格實在偏貴，內容就普普通通。」
　✅「票有用成，只是覺得換算下來不太划算，自己買可能更便宜。」
　✅「整體 CP 值不高，以這個價位來說會期待更多一點。」
　❌「現場才知道還要另外付入場費，頁面完全沒寫。」——是費用客觀上沒揭露，不是主觀嫌貴，不屬本域、棄權。
　❌「導遊一直施壓要大家買高價自費項目。」——是現場施壓消費的客觀問題，不是主觀價值評價，不屬本域、棄權。
　❌「內容根本被偷工減料、東西也少給。」——東西客觀縮水是瑕疵事實，不是單純主觀嫌不值，不屬本域、棄權。
　❌「休息時間有點長，還好旁邊剛好有超市可以逛，這樣安排也蠻好的。」——抱怨在原文中**已被自己化解**（明說安排也不錯），不構成問題點、不歸因。
　❌「整體很值得，只是希望某個景點可以多留一點時間就更好了。」——是對**未來的建議或期望**，沒有指出任何已經發生的落差，不構成問題點、不歸因。
　❌「甜品味道一般般，菜色款式也不多。」——指向具體餐飲對象的品質與選項不足，屬交付物品質的客觀瑕疵，不屬本域、棄權。
　❌「純粹覺得規模、內容不如想像，跟價格無關。」——與價格無關 → 歸 C-6-3，不屬本項。

■ C-6-3 內容期待落差
判定範圍：行程／服務依約正常完成、無取消縮水、與頁面相符，旅客只憑過往經驗或想像比較，或落差來自**公共場域的一般遊客量、動線指標不易辨識、其他遊客的行為**（非商家失職所致；原文若指出擁擠出在**用餐場域的座位不足**，或**超收／超載已達人身安全風險**——那是場域配置客觀不足，不屬本域、棄權），覺得規模比想像小、內容沒想像豐富、氛圍景色普通、不如別處好玩，純屬主觀心理落差。含依表執行的行程節奏不滿：嫌停留短、嫌趕、嫌拉車遠、嫌購物站多，**且原文未寫出執行偏離表定的具體事實、也未指出任何現場人員的具體失職**（未告知／未引導／未派發／態度差）——原文未提及頁面寫了什麼時**不預設頁面未寫明**，這類一律歸本項。反饋聚焦價格對比 → 歸 C-6-2；落差主因是天氣天災等外力 → 歸 C-6-4／C-6-5。
　✅「行程都有跑完，只是感覺沒有網路上寫的那麼驚艷，可能是我自己期望太高。」
　✅「餐點味道普通沒到很難吃，但也沒有想像中厲害。」
　✅「自助餐時段人太多，大家鬥搶食物你推我撞，體驗一般。」
　✅「行程超好玩，缺點是場地路線有點像迷宮，一直找不到出口。」
　✅「園區看起來比想像中小，不過設施都正常開放，就是沒想像豐富。」
　✅「才剛拍完照就上車，覺得停留有點趕。」——原文只嫌趕、未寫出與表定不符的具體事實，歸本項。
　❌「肉品聞起來有點酸，吃了肚子不舒服。」——東西本身有異味、不新鮮，是客觀瑕疵，不是主觀嫌普通，不屬本域、棄權。
　❌「導遊態度很冷淡，問問題都愛理不理。」——是現場服務態度的客觀失職，不是主觀期待落差，不屬本域、棄權。
　❌「寫和牛結果現場給的是普通牛肉。」——實際與頁面所寫不符，是客觀瑕疵事實，不是主觀落差，不屬本域、棄權。
　❌「行程被臨時取消一個景點、還提早收團。」——是現場執行偏離表定、客觀縮水，不是依表正常執行，不屬本域、棄權。
　❌「司機很冷漠、放生旅遊完全不知狀況，兩人花快一萬元很後悔。」——主訴是現場人員失職，「花多少錢很後悔」只是附帶的感嘆，不是獨立的價值感落差陳述，不屬本域、棄權。
　❌「以這個價錢內容實在太少、不值。」——聚焦價格對比 → 歸 C-6-2，不屬本項。

　❌「自助餐位子根本不夠坐，大家只能站著吃。」——是用餐場域座位配置客觀不足，不是其他遊客造成的體驗落差，不屬本域、棄權。
　❌「行程有點趕，而且導遊完全沒提門票的事，也沒說下車後在哪等他派票。」——原文已指出現場人員的具體失職，主訴不是純主觀的節奏感受，不屬本域、棄權。
■ C-6-4 天候與自然因素
判定範圍：天候／天災／自然條件（下雨、起霧、颱風、地震、退潮、季節、能見度、花況動物不賞臉）導致行程取消、設施停開或體驗打折，且原文未指出商家在告知或應變上有失職；核心是「天然外力不可控、非商家過失」。鏡像判準：外力事件本身屬本項；若商家對該風險明知卻未告知、未取消或應變失當（有具體失職事實），失職那部分是客觀失職事實、不屬本域、棄權。並存成立條件——唯有反饋另含獨立針對外力本身的陳述（而非僅把外力當成失職抱怨的背景鋪陳），外力部分才與失職並存歸本項；若整句主訴就是商家失職（如「颱風警報商家卻沒通知就直接取消」），該問題點整體屬失職、本域棄權。非天候的外部事件（疫情、罷工、場館關閉）→ 歸 C-6-5；純主觀覺得不驚艷、無天候事實 → 歸 C-6-3。
　✅「當天下大雨纜車臨時停駛，這也是沒辦法的事。」
　✅「因為颱風接送行程被取消，天氣真的不可控。」
　✅「起了大霧主要的景什麼都看不到，只能說運氣不好。」
　✅「颱風天纜車停駛是真的沒辦法，但商家連一通通知都沒有。」——前半句是**獨立針對外力本身**的陳述（不是把外力當成抱怨的背景鋪陳），外力這一項成立、歸本項；後半句的通知失職是另一個客觀事實，歸別處、與本項並存不互相抵銷。
　❌「因颱風航班取消無法參加，供應商仍堅持不退款，連船費也不退。」——原文主訴是**供應商的處置**（拒退、判全損），外力只是觸發背景；**外力被當成抱怨的背景鋪陳時一律不屬本域、棄權**。
　❌「氣象局早就發布颱風警報，商家卻沒提前通知就直接取消也不退款。」——是商家對已知風險的告知與應變客觀失職，不是單純外力，不屬本域、棄權。
　❌「下雨天路面濕滑，現場卻連個防滑墊或提醒都沒有。」——指控的是商家對天候風險的現場處置失職，非天候本身不可控，不屬本域、棄權。
　❌「就是覺得體驗普通沒特別驚艷，天氣其實還不錯。」——是純主觀期待落差、無外力事實 → 歸 C-6-3，不屬本項。

■ C-6-5 外部突發事件
判定範圍：非天候的外部突發事件（疫情／防疫政策、第三方運輸罷工延誤、場館臨時關閉、公共事件管制）導致行程取消、縮減或改期，且商家已依規則協助或無應變義務；核心是「外部事件不可控、非商家過失」。第三方運輸業者（航空／鐵路等）自身的罷工、延誤屬不可控外力，仍歸本項。鏡像判準：事件本身屬本項；若商家明知事件仍未告知、應變失當（有失職事實），失職那部分是客觀失職事實、不屬本域、棄權。並存成立條件——唯有反饋另含獨立針對事件本身的陳述（而非僅把事件當成失職抱怨的背景鋪陳），事件部分才與失職並存歸本項；若整句主訴就是商家失職（如「罷工害班機取消，商家卻完全沒通知替代方案」），該問題點整體屬失職、本域棄權。天候／天災類 → 歸 C-6-4。
　✅「因為疫情場館臨時關閉，只好取消行程。」
　✅「遇到航空公司罷工，班機直接取消，接送行程也跟著泡湯。」
　✅「鐵路工會罷工導致原本安排的交通延誤了好幾個小時。」
　✅「地鐵罷工這種事誰也料不到，只是店家事後完全沒協助改期。」——前半句**獨立陳述外力本身**，該項歸本項；後半句的協助失職是另一個客觀事實，各自成立。
　❌「疫情期間想改期，客服都不回也不處理。」——是售後往來的客觀失當，不是單純外力事件，不屬本域、棄權。
　❌「說是場館臨時關閉，但其實是他們自己排班出錯。」——原文指出停開肇因於商家自身安排，非外部突發事件，不屬本域、棄權。
　❌「罷工害班機取消，結果商家完全沒有主動通知任何替代方案。」——是商家對事件的告知與應變客觀失職，不是單純外力，不屬本域、棄權。

■ C-6-6 資訊誤讀
判定範圍：頁面／憑證上的說明本身正確清楚，旅客自己沒看仔細或會錯意——下單選錯天數／張數／版本、誤解涵蓋範圍，或已寫明的兌換步驟／需自備配件／使用須知沒讀到；核心是「說明就在那裡、旅客沒吸收」（含自承沒看與下單操作疏失）。若頁面本身語意不清或根本沒寫（說明客觀有缺漏）、旅客未自承沒看而僅現場被規則卡住（不預設旅客已理解）、或系統重複扣款出票（客觀故障），則非本項。
　✅「訂的時候沒注意看是一日券，結果只能用一次，是我自己選錯了。」
　✅「以為方案含接送，後來才發現自己會錯意，頁面其實寫得清楚。」
　✅「到現場才知道要先去櫃檯換票才能用，其實憑證上有寫，是我自己沒注意到。」
　✅「租借的相機沒附電池，後來翻了說明才發現其實有寫需要自備。」
　❌「同一個行程被扣款兩次，客服說是系統問題。」——是系統重複扣款的客觀故障，不是旅客沒讀，不屬本域、棄權。
　❌「頁面寫買一送一，結果現場說沒有這個活動。」——是頁面所寫與實際不符的客觀瑕疵，不是旅客沒讀，不屬本域、棄權。
　❌「查了半天官網完全沒寫怎麼兌換，到現場才發現要另外排隊。」——是兌換規則客觀沒寫清楚，不是旅客沒讀，不屬本域、棄權。
　❌「頁面根本沒寫要另外收這筆費用，才讓人誤會。」——是說明客觀有缺漏，不是旅客沒看仔細，不屬本域、棄權。

<judgment_rules>
- If 傾向為 negative → 列出反饋中所有明確命中本域的問題，最多 3 條，寧缺勿濫；If 傾向為 neutral（整體滿意但含具體問題點）→ 只歸因具體問題點，被稱讚的面向不歸因。
- 輸出數量上限為 3 條；在此上限內須由下列準則收斂，嚴禁灌水湊數：
　- 去重與合併：同一問題點只歸一條；同一具體事實的不同措辭必須合併為一條，不得拆成多條，嚴禁換句話說重複計數。
　- 獨立性判準：兩個問題點唯有「指向不同的具體事實或不同面向」才算彼此獨立、可各歸一條；此與 facet code、受評對象是否相同無關——同一 facet code、同一對象下，只要是語義不同、可獨立成立的兩個事實（如同一導遊的態度差與專業不足），仍各記一條。
　- 證據門檻：每一條都必須有本域可逐字引用的 evidence_quote；無逐字證據者不得輸出。
　- 顯著性取捨：命中超過 3 條時，依嚴重度與篇幅取前 3 條、次要／附帶者從略。
　- 信心門檻：把握度未達「明確」者一律不報；邊緣或低信心的 code，NEVER 為求完整而硬湊或疊加。只在反饋真存在多個各自獨立且明確的問題點時才多歸。
　- 真問題門檻：每一條歸因都必須對應一個具體、可指認的問題事實（何謂真問題、何謂空泛感想，見 <abstain_rules>）。
- confidence 0~1 誠實反映把握度，NEVER 灌高。
- summary 1~3 條去重，務必含一條 lang="zh-tw"（台灣繁體中文書面語，一句話簡明扼要）；原文非繁中另附一條原文語言碼摘要。
</judgment_rules>

<abstain_rules>
**棄權（critical）**：以下任一情況輸出 {"attributions":[]}：
- 問題點不符合本域核心判準。
- 問題無法對應到 <facet_catalog> 的任何面向。
- 缺少可逐字引用的原文證據。
NEVER 因「找不到更貼切的面向」而硬歸低信心 code。
- **無真問題即棄權（不得硬湊）**：整體傾向即使為 negative／neutral，若通篇找不到本域一個「具體可指認的問題事實（不滿、遺憾或客觀瑕疵）」，一律輸出 {"attributions":[]}；NEVER 因「判為負向／中性就必須生一條歸因」而硬歸——寧可留空。
- **空泛與否看「有沒有指涉對象」，不看語氣強弱**：針對**整體**而未指向任何具體對象的評價（「整體中規中矩」「不過如此」「沒什麼特別」「這趟還可以啦」），不構成問題點、不歸因。**但只要評價指向一個具體對象——某道餐點、某項服務、某個設施、某段流程——即使語氣極輕、只是「一般」「普通」「不多」「有點慢」，那就是一個真問題點，應歸因**（「服務一般」指涉服務、「甜品味道一般」指涉甜品味道、「款式不多」指涉品項數量，三者都要收）。同理，只要點出具體可指認的事實落差或瑕疵（某項沒做到／東西有問題／不如約定／明確遺憾），即使未帶情緒字眼，仍是真問題。
</abstain_rules>
